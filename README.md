
# Todo List

A simple and interactive Todo List built with **HTML, CSS, and JavaScript**.

This project was created to practice DOM manipulation, JavaScript logic, event handling, and managing application state with arrays and objects.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* ✏️ Edit existing tasks

* 💾 Persistent tasks using `localStorage`

## 🛠️ Built With

* **HTML5**
* **CSS3**
* **JavaScript (ES6+)**
* **LocalStorage API**

## 🎯 What I Learned

While building this project, I practiced:

* DOM manipulation
* Event listeners
* Dynamic HTML elements
* Managing application state
* Form/input handling
* Working with `localStorage`
* Rendering data to the DOM



## 📚 Project Purpose

This project is part of my journey learning JavaScript and front-end development.

The goal was not just to build a Todo List, but to understand how JavaScript can manage data and dynamically update a webpage based on user interactions.
